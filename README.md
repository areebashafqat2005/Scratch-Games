# Scratch Games Flappy Bird & Skinned Flappy Bird

This repository contains two games developed using **Scratch** as part of my Programming Fundamentals coursework during my **1st semester of BS Computer Science**.

The projects helped me develop an early understanding of programming concepts such as event-driven programming, loops, conditions, variables, collision detection, scoring, and game logic.

## Projects

### 1. Flappy Bird

A Scratch-based implementation inspired by the classic Flappy Bird game.

**Main features:**

* Player-controlled bird movement
* Gravity and jumping mechanism
* Obstacles/pipes
* Collision detection
* Score tracking
* Game-over condition
* Continuous gameplay

**Source File:** `Flappy-Bird.sb3`

**Gameplay Video:** `gameplay.mp4`

---

### 2. Skinned Flappy Bird

A customized version of the Flappy Bird project with modified visual elements and game appearance.

**Main features:**

* Bird movement and jumping
* Obstacles/pipes
* Collision detection
* Score tracking
* Game-over condition
* Customized/skinned visual design

**Source File:** `Skinned-Flappy-Bird.sb3`

**Gameplay Video:** `gameplay.mp4`
